# 🥑 Retail Data Warehousing Project – The GUAC Stop

Welcome to the **Retail Data Warehousing** project for a fictional retail store, **The GUAC Stop**. This project simulates the end-to-end implementation of a cloud-based data warehouse and retail analytics system.

## 📌 Objective

To transform raw retail data into actionable insights by:
- Understanding business challenges via stakeholder interviews.
- Designing a cloud-based data warehouse solution.
- Building ETL pipelines to automate data flow.
- Visualizing performance metrics using Power BI.

## 📈 Project Workflow

1. **Stakeholder Interview & Problem Identification**  
   - Understand sales data issues, reporting delays, and the need for centralized analytics.

2. **Cloud Data Warehouse Proposal & Implementation**  
   - Hosted on **Oracle Cloud** with secure, scalable architecture.

3. **Dimensional Modeling (Star Schema)**  
   - Includes `Sales Fact` and various `Dimension` tables (e.g., Product, Store, Time, Customer).

   ![Dimensional Modeling](Dimensional%20Modelling.png)

4. **ETL Pipeline Development**  
   - Created with **Apache HOP** to extract, transform, and load data into the warehouse.

   ![ETL Pipeline](Apache_hop_ETL%20pipeline.png)

5. **Retail Analytics Dashboard**  
   - Built using **Power BI** to deliver KPIs like sales trends, top-selling items, and region-wise performance.

   ![Power BI Dashboard](PowerBI%20dashboard.png)
